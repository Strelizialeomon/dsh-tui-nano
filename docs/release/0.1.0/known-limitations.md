# 已知限制与未验证项（0.1.0）

本清单只记录有证据依据的限制。未测项保持「未验证」，不写成「通过」。阻断项另见 `release-conclusion.md`。

## 1. 平台与输入

| 限制 | 影响 | 状态 |
| --- | --- | --- |
| 只支持 macOS arm64 + Ghostty | 其他终端、Windows、Linux、x86_64 不可用 | 承诺范围外 |
| 真实系统输入法组合态未测 | 中文输入法候选窗、组合中 Enter 的行为没有真实系统级证据 | 未验证；S02 与 S13 均未覆盖 |
| 60/100 列之外未验收 | 任意宽度不承诺 | 未验证 |
| 滚轮手感 | Ghostty 已验证可滚动；xterm.js/其他终端的设备曲线未测（S03 验收项只部分满足） | 部分未验证 |
| inline 渲染、鼠标窗口缩放后的布局 | 不承诺 | 范围外 |

## 2. 集成与生命周期

| 限制 | 影响 | 状态 |
| --- | --- | --- |
| 强杀/断电/逃逸后代 | macOS 不能保证追到所有逃逸后代，只保证本窗口拥有的进程组 | 官方限制 |
| 宿主崩溃后的会话恢复 | 可恢复性依赖官方持久化；未全部注入真实崩坏存储 | 部分未验证 |
| 单条官方持久事件超过 256 KiB 帧上限 | 该事件显式失败并提示 `--resume`，不无限重连 | 已知限制（S02） |
| 跨进程 KV 变更可见性 | 官方 storage-domain 限制，Nano 不承诺跨进程实时一致 | 官方限制 |
| 同一根会话第二个窗口 | 在挂载账本处拒绝；不接管、不删除锁 | 已实现，S13 已复核 |
| 调度投递 | 非严格一次；周期只补最近一次；无暂停 API，只能删除 | 官方限制 |
| 归档 API、探针写失败、历史多记录游标、官方内部 flush 后写失败 | 没有真实注入证据 | 未验证（S11） |
| 未知 shell 的活动观察、`less`/`tmux` 端到端、真实鼠标上报 | 未单独验收；与 `vim` 共用 PTY/alt-screen/VT 路径 | 未验证（S09） |

## 3. 功能边界

| 限制 | 影响 | 状态 |
| --- | --- | --- |
| 外部子代理 provider（ACP/SDK/Codex/Claude Code） | 只在目录夹具中覆盖，未启动真实外部 provider | 未验证（S12） |
| one-shot 子代理历史 | 只有夹具与单测，没有真实 one-shot provider | 未验证（S12） |
| 子代理容量上限（默认 8） | 映射由单测覆盖，未真实创建 8 个以上 | 未验证（S12） |
| 子代理图片续聊 | 只发送文本，未真实上传图片 | 未验证（S12） |
| 子代理鼠标点击 dock/返回 | 真实 TUI 证据使用键盘路径 | 未验证（S12） |
| 长压缩进行中取消 | 依赖模型额度与长历史，真实路径未跑 | 未验证（S07） |
| 真实会话列表恢复后的历史一致性 | 历史读取属 S01/S02，S07 只验标题与恢复身份 | 未验证（S07） |
| 切换失败后的「无宿主」真实终端屏与内容隔离 | 映射有单测，未在真实 PTY 制造占用窗口 | 未验证（S07） |
| 压缩成功/进行中取消/全部失败文本 | 单测覆盖，真实长压缩未跑 | 未验证（S07） |
| 图片真实模型消费 | 无付费预算；官方附件服务已真实验证 | 未验证（S06） |
| 超限图片/像素/边长拒绝 | 本地检查与 fake store 限额覆盖判定分支，未用真实超限图触发官方拒绝 | 未验证（S06） |
| 绝对路径 `@` 补全 | 只在 Rust 格式化层测过，官方发现按相对路径工作 | 已知限制（S06） |
| 远程技能 provider | 只接官方 filesystem provider | 未验证（S05） |
| 工作目录变化后的技能/规矩重载 | 官方链重载有单测，真实窗口级切换未跑 | 未验证（S05） |
| Monitor 长时间空闲 `quiet` 注入 | 只验证空闲数秒；未验证数分钟以上 | 未验证（S10） |
| 首次启动显示配置/凭据/全局指令来源 | 应用启动没有来源文案；安装输出与 `Alt+R` 只是部分替代 | **阻断项 B5** |
| 真实模型付费链路 | 子件证据用真实模型；S13 的 Ghostty 验收使用本地 mock，不重复产生费用 | 见子件证据 |

## 4. 视觉与主题

| 限制 | 影响 | 状态 |
| --- | --- | --- |
| 输入框上下文占比线缺失 | 与 design-contract / S13 §1 冲突 | **阻断项** |
| 主会话约 500ms 忙碌指示缺失 | 与 design-contract 冲突 | **阻断项** |
| diff 背景只硬编码深色 | 浅色终端下与 light token 不一致 | **阻断项** |
| 装饰性 emoji | 实现为 0，符合契约 | 通过 |
| 4ch 行号槽 + 2ch 标记槽、8 行差异预算 | 代码与单测一致 | 通过 |

## 5. 证据边界

- 自动化测试全绿不等于视觉和交互符合；本清单把两者分开记录。
- 本目录截图只来自合成 HOME/workdir；用户真实路径、用户名、主机名、密钥和用户正文不进入证据。
- 未脱敏原件不进入仓库；`docs/release/` 中只有窗口级截图与合成输出。
