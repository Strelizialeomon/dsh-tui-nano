## 1. 布局槽位

主界面从上到下固定为以下行槽位；除 `Min(3)` 外，高度为 0 的槽位不占行。

| 槽位 | 高度 | 内容 |
| --- | --- | --- |
| 标题行 | 1 行 | 应用名、连接/回合状态；可附会话序号、队列数、上下文参考值、任务/监听计数。不换行。 |
| 主视图 | `Min(3)`，占满剩余 | transcript；打开会话/任务/技能/规矩/子代理全部列表时由该面板占用同一区域。交互终端打开时整屏替换。 |
| 队列 dock | 0–5 行 | 官方 inbox 前 4 项 + 标题行；无队列时 0 行。 |
| 补全弹层 | 0–7 行 | `@file` 候选前 6 项 + 标题行；隐藏时 0 行。 |
| 子代理 dock | 0–6 行 | 最多 4 个直接子代理 + 1 个溢出入口 + 标题行；子代理视图/无入口时 0 行。 |
| 输入块 | 3–8 行内容 + 2 条边框 | 上下边框各 1 行；内容含附件卡片（最多 3 张 + 1 行溢出提示）和输入文本（最多 8 个可视行，超出按光标滚动）。决策卡占用同一槽位。 |
| 底部状态行 | 1 行 | 工作目录（basename）+ 权限/安全状态 + 瞬态提示/键位提示。不换行。 |

覆盖层规则：

- 决策卡（审批/问卷/计划审阅）替换输入块，不覆盖 transcript 和标题行。
- 会话、任务、技能、规矩、子代理全部列表替换主视图，标题行与输入块保留。
- 调度面板替换主视图并占用标题/主体/底行三段；交互终端整屏替换。
- 60 列与 100 列使用同一槽位结构；宽度不足时截断/换行，不改变槽位顺序，不横向溢出。

输入框上下文线（冻结要求，当前实现未满足，见 §8）：

- 输入块上、下边框各有一条单单元格高的上下文占用线，左右同步。
- 左侧按占用比例着色，右侧为普通边框色；正常为 accent，约 80% 及以上为 warning，约 95% 及以上为 error，占用未知时整条回退普通边框色。
- 不写百分比数字；精确值走会话/上下文面板。

## 2. 键位

键位按「焦点归属」定义。覆盖层拥有焦点时，下层快捷键不泄漏；子代理视图只接收子地址相关按键。

| --- | --- | --- |
| 全局 | `Ctrl+C` / `Ctrl+Q` | 退出 |
| 全局 | `F12` | 进入/返回交互终端 |
| 全局 | `Ctrl+P` | 打开命令面板；面板打开时关闭 |
| 全局 | `Ctrl+G` | 打开/关闭调度面板 |
| 全局 | `Ctrl+T` | 打开/关闭任务面板 |
| 全局 | `PageUp` / `PageDown` | transcript 翻页 |
| 全局 | `Ctrl+End` | transcript 回到底部 |
| 全局 | `Tab` | 输入焦点 / 队列焦点切换 |
| 输入 | `Enter` | 发送或排队（空内容拒绝并保留草稿） |
| 输入 | `Shift+Enter` / `Ctrl+J` | 换行 |
| 输入 | `Alt+Enter` | 插话（steer） |
| 输入 | `@` | 打开文件路径补全 |

| 队列焦点 | `↑` / `↓` | 选择队列项 |

| 任务详情 | `↑` / `↓`、`PageUp` / `PageDown`、`k`、`m`、`r`、`Esc` | 滚动、停止、Monitor、跟随刷新、返回 |
| Monitor 视图 | `↑` / `↓`、`s`、`b`、`r`、`PageUp` / `PageDown`、`Esc` | 选择、停止监听、重置预算、刷新、滚动、关闭 |

| 计划审阅 | `↑` / `↓`、`Enter`、`1`、`Esc` | 选择、确认、展开/收起、取消 |

空 dock 时 `Alt+L` 仍可打开子代理全部列表。`!` 是输入文本而非快捷键：以用户权限执行，输出作为合成 user 上下文注入，不立即唤醒模型；`!!` 只是普通文本。

## 3. 主题 token

颜色只表达主次与状态。终端调色板决定最终 RGB；下表给出实现应使用的角色与参考色值。

| token | 角色 | dark 参考 | light 参考 | TUI 角色 |
| --- | --- | --- | --- | --- |
| `bg` | 终端底色 | `#17191d` | `#f6f3ed` | 终端默认背景 |
| `fg` | 正文 | `#e8e6e0` | `#343945` | 默认前景 |
| `muted` | 次要文字/槽位/未激活 | `#8d95a6` | `#626978` | `DarkGray` |
| `accent` | 强调/用户输入/选中 | `#7da1de` | `#365f9d` | `Cyan` |
| `error` | 错误/失败 | `#da8a93` | `#a33e4c` | `Red` |
| `warning` | 警示/审批标题/过期 | `#d8b270` | `#855b18` | `Yellow` |
| `success` | 完成/可用 | `#9ac4a6` | `#315f3e` | `Green` |
| `rule` | 边框/分隔线 | `#424953` | `#c4c6c9` | `DarkGray` |
| `hover` | 悬停/聚焦行底 | `#242b35` | `#e8e8e5` | 反显或选中底色 |
| `selected` | 选择区 | `#3b4a66` | `#d5def2` | `fg=Black, bg=Cyan` |
| `diff_add` | 新增行底 | `#24382c` | `#dcebdd` | 深色 `Rgb(0,42,0)`；强调 `LightGreen` + bold |
| `diff_del` | 删除行底 | `#38252a` | `#f1dcdf` | 深色 `Rgb(48,0,0)`；强调 `LightRed` + bold |
| `diff_add_word` | 新增词底 | `#385b42` | `#b6d6bc` | 深色 `Rgb(0,88,0)` |
| `diff_del_word` | 删除词底 | `#653641` | `#e9bac3` | 深色 `Rgb(96,0,0)` |

主题规则：

- 正文用 `fg`；次要内容用 `muted` 但仍需可读。颜色只服务于主次和状态，不靠颜色单独传递信息。
- 深浅主题由终端决定；TUI 不读取也不覆盖终端主题。diff 底色在浅色终端下必须仍可读（当前实现只硬编码深色底，见 §8）。
- 上下文占用线：正常 `accent`；`>= 80%` 用 `warning`；`>= 95%` 用 `error`；未知用 `rule`。
- 子代理状态灯：running `accent` 闪烁；completed `success`；aborted/refusal/max-tokens `warning`；error `error`；unknown/inactive `muted`。
- 装饰性 emoji 默认 0 个。原文、代码和日志中的字符不过滤。允许的固定符号：`▶`、`●`、`○`、`…`、`↑`、`↓`、`←`、`→`、`←`、`[← 返回]`。

## 4. 间距与行预算

| 对象 | 预算 |
| --- | --- |
| 代码差异 | 默认最多 8 个可视行；展开后不限；超预算显示「还有 N 行」。多处修改共享 8 行预算，优先保留第一处完整变更。 |
| 行号槽 | 4 个单元格（右对齐）；无真实坐标留空。 |
| 标记槽 | 2 个单元格（`+`/`-`/空格居中）；与行号槽之间 1 个空格。 |
| 命令标题 | 默认 1 个可视行；超出省略。 |
| 运行输出尾 | 2 个可视行，只在原位刷新。 |
| 输入文本 | 最多 8 个可视行，超出按光标滚动。 |
| 附件卡片 | 最多 3 张 + 1 行溢出提示。 |
| 子代理 dock | 最多 4 个直接子代理 + 1 行溢出入口。 |
| 正文缩进/边距 | 终端单元格：左右 2ch 的等价比例，不使用浏览器 px。CJK 按 2 单元格计算。 |

## 5. 动效与 reduced-motion

| 动效 | 冻结值 |
| --- | --- |
| 子代理 running 状态灯 | 800ms 完整周期，亮/暗各 400ms，离散切换（不渐隐） |
| 主会话忙碌指示 | 约 500ms 更新一次；只有一处持续变化 |
| 其他 | 已完成工具、思考、任务保持静态；不因新消息自动收起已展开内容 |

reduced-motion 检测契约：

- 环境变量 `NANO_REDUCED_MOTION=1` 或 `true` 关闭持续动效；未设置或设为其他值视为关闭 reduced-motion。
- 终端能力探测不作为首版判据；没有设置项 UI，也不要求 Ghostty 提供开关。
- 开启时：子代理状态灯停在亮相、主会话忙碌指示静止；状态文字与颜色仍保留，信息不丢失。
- 该检测结果是进程级、每个窗口独立读取；修改后需重开窗口生效。

## 6. 文本与状态语义

- 用户消息用 `accent` 加粗；助手正文用 `fg`；过程/思考/命令摘要用 `muted`；错误摘要用 `error`。
- 审批卡先完整显示待执行命令；允许/拒绝之外不提供「始终允许」。
- 未知状态不显示为成功：`unknown`/`inactive` 用 muted，`failed` 用 error，`completed` 用 success。
- 底部状态行常驻 cwd + 权限；瞬时提示可以追加，但不得挤掉 cwd/权限。
- 控制字符在显示前替换为 `?`；复制/原始记录不受展示归一化影响。

## 8. 当前实现偏差（2026-10-22 核对）

以下偏差按 S13 §6「交付物缺失/契约冲突」记录，不在 S13 内修复：

| 偏差 | 契约要求 | 当前实现 | 证据 |
| --- | --- | --- | --- |
| 输入框上下文线缺失 | 上下边框各一条单单元格高的占比色段，80% warning / 95% error | 输入框只有普通四边框；上下文数字显示在标题行 `ctx …`，阈值 60% warning / 80% error | `crates/nano-app/src/ui.rs:251`、`crates/nano-app/src/ui.rs:2349` |
| 主会话忙碌指示缺失 | 约 500ms 的低频字符忙碌指示 | 标题行只改状态文字/颜色，无周期性字符指示 | `crates/nano-app/src/ui.rs:222` |
| 浅色主题 token 未落地 | dark/light 两套 token，diff 底色需分别可读 | diff 底色硬编码深色 `Rgb(0,42,0)` / `Rgb(48,0,0)`，浅色终端无对应 token | `crates/nano-transcript/src/render.rs:670` |

已核对一致项：4ch 行号槽 + 2ch 标记槽、8 行差异预算、命令 1 行预算、子代理 dock 4+1、状态灯 800ms、reduced-motion 环境变量、装饰性 emoji 为 0、底部 cwd/权限常驻、键位未见冲突。
