## 1. 目标与边界

目标：让真实 TUI 的视觉层与设计稿一致，解决「结构对、观感错」。范围只限展示层：标题、底栏、transcript、输入区、决策卡、子代理 dock 与详情。

不做：

- 不改协议、桥接、官方服务、凭据、数据所有权。
- 不新增业务功能；Skip/倒计时、审批滚动、上下文可展开等既有功能保留，只改呈现。
- 不冻结浏览器 px、14px 字号、22px 行高；字号与行高由用户终端控制。
- 不用浏览器样稿替代真实终端验收。

拥有：`crates/nano-app/src/ui.rs`、`crates/nano-transcript/src/render.rs` 的展示层；`docs/design/2026-10-22-visual-alignment/checklist.md`；本 spec；`design-contract.md` 顶部的一行指向说明。
不碰：`crates/nano-runtime`、`crates/nano-conversation`、`crates/nano-decisions` 的数据模型、`bridge/`、`protocol/`、官方 profile 与凭据。

## 3. 终端映射规则

- 单位：终端单元格。左右边距 2ch：标题、transcript、输入区、底栏、子代理 dock 内容两侧各留 2 个单元格；CJK 按 2 单元格计。60/100 列同一套槽位，不横向溢出。
- 主界面槽位（从上到下）：标题 1 行（子代理详情时为标题 1 行 + 子代理行 1 行）→ 主视图 `Min(3)` → 队列 dock 0–5 → 补全弹层 0–7 → 活动行 0–1 → 输入块 1–8 行内容 + 2 条边框（总高 3–10）→ 底栏 1 行 → 子代理 dock 0–6。决策卡替换输入块；子代理详情替换主视图。
- 颜色：正文 `fg`；次要 `muted`（DarkGray）；强调/用户 `accent`（Cyan）；错误 Red；警告 Yellow；成功 Green；边框 DarkGray。精确 RGB 由终端调色板决定。
- 字重：结论、标题、用户消息、选中项用 `Modifier::BOLD`；终端不支持粗体时仍保留颜色/位置语义。
- 符号：只允许 `▶`、`▸`、`▾`、`●`、`○`、`…`、`↑`、`↓`、`←`、`→`、`[← 返回]`；装饰性 emoji 为 0。
- 动效：忙碌指示约 500ms 一次；子代理 running 灯 800ms 亮/暗；`NANO_REDUCED_MOTION=1|true` 时两者静止。
- 主题：`NANO_THEME=light` 时 diff 使用浅色 token（新增底 `#dcebdd`、删除底 `#f1dcdf`、新增词底 `#b6d6bc`、删除词底 `#e9bac3`，文字用深色）；未设置或 `dark` 时用现行深色 token。首版不读取 `COLORFGBG`、不发 OSC 11 查询。

## 4. 逐组件验收与冲突裁决

逐项判据以 `checklist.md` 为唯一正文；完成判定必须逐项勾选，不能用「大部分符合」代替。以下只列必须写死的裁决：

### 4.1 三个阻断项

1. **输入框上下文占用线**：输入区上下边框各一条单单元格高的色段，左侧按占用比例着色，右侧普通边框色；正常 `accent`，≥80% `warning`，≥95% `error`，占用未知时整条回退普通边框。不写百分比文字；精确值走会话/上下文面板。
2. **活动行/忙碌指示**：transcript 与输入区之间增加 0–1 行活动行；running 显示「正在运行… · Esc 可停止」，等待审批显示「等待你的授权」，等待问卷显示「等待你的选择」；忙碌时 2ch 宽字符指示约 500ms 变化一次；空闲时 0 行。只保留这一处持续变化。
3. **浅色 diff token**：按 §3 的 `NANO_THEME` 选择深/浅两套 diff 底色与行内强调；浅色终端下不得出现深色块。

### 4.2 七条口径冲突

| # | 冲突 | 裁决 |
| --- | --- | --- |
| 1 | 标题行内容 | 只放应用名（`nano`，设计稿的 `dsh-tui` 视为占位）+ 当前目录；连接/回合状态不再常驻；错误/断开以底栏中段瞬态显示；连接详情走会话/上下文面板，模型/强度/权限走 `/model` + bare `/permission`，键位说明走 `nano --help`（补齐缺键）。 |
| 2 | 底栏排列 | 左「权限：…」，右当前目录，中间放瞬态提示；中间先截断，两端不得被挤掉。 |
| 3 | 上下文块常驻 | 同一轮连续的普通注入上下文合并为一条「上下文 N 段 · 点击展开」，默认收起；展开后仍可看每段原文；bash/monitor 保留原标签，不参与合并。S03 的逐条 1 行摘要由本裁决取代。 |
| 4 | 输入最大高度 | 保留 8 个可视行的功能上限；视觉按设计稿的上下边框、2ch 边距、占位与占用线，不采用设计稿的约 4 行上限。 |
| 5 | 问卷额外提示 | Skip/倒计时保留，压成一行 muted 页脚；卡片底部只留键位提示；不额外加框、描述只渲染一次。单选不显示复选框，多选才显示 `[x]/[ ]`。等待文案在活动行，不放在卡片底部。 |
| 6 | 审批命令窗口 | 不再固定 5 行窗口；按卡片可用高度显示完整命令，超出再滚动；短命令一次看全。 |
| 7 | 子代理 dock 顺序 | 按设计稿：输入区 → 底栏 → 子代理 dock；dock 在屏幕最底部。保留 `N local agents` 顶边框计数与右侧活动/时长；详情头保留主标题 + 新增子代理行；详情底栏保留「子代理审批由官方拒绝」事实。旧契约的「dock 在输入块之前」由本裁决取代。 |

### 4.3 其余必改项（摘要）

- 用户消息：`> ` 前缀 + accent 加粗，整块展示；删除单独一行「你」。
- 助手正文：删除「助手」标签行；标题去掉 `#` 后加粗，行内 `**…**` 加粗，列表用 `-` 前缀；段间一行。
- 过程块：`▸` + 工具名（官方名称，如 Bash/Read/Edit；思考固定「思考」）+ 名称/命令 + 右侧状态/用时/`+N 行`；不再用「命令/文件/工具」彩色中文分类标签。
- 文件差异：`▸ Edit path +N -M`，统计右对齐；状态行；4ch 行号 + 2ch 标记；8 行预算；整行底色 + 行内强调。
- 输入区：去掉四边框与常驻快捷键标题，只保留上下两条线；主会话 `> 继续提问…`、子代理 `> 给 <任务名> 发送消息…` 占位；右侧 `↑` 发送按钮；快捷键移入 `nano --help`（补齐缺键）。人工命令「用户权限，不是 Agent 授权」、附件、队列编辑、子代理 gate（只读/仅停止/读取历史中）提示必须保留在输入区或底栏瞬态，不因视觉简化删除。
- 问卷卡：顶部 accent 线，无外框；题目加粗；编号 + focus 指针；描述另起一行缩进 5ch、只渲染一次；底部只留键位提示，Skip/倒计时压一行 muted 页脚；单选不显示复选框，多选显示 `[x]/[ ]`。等待你的选择在活动行显示。
- 审批卡：顶部 accent 线；首行白色加粗问句（Bash 示例「是否运行这条检查命令？」，其他工具用官方工具名）；完整命令；选项 1/2，描述下一行 5ch 缩进；不提供「始终允许」。等待你的授权在活动行显示。
- 计划审阅：设计稿未展示，沿用 S03 §5 的紧凑卡：标题 + 两行摘要 + 查看/批准/修改。
- 子代理 dock：顶边框只留 `N local agents`（保留 S12 验收项），去掉键位说明；每行「指针 + 状态灯 + 名字（弹性）+ 右侧活动/用时」；mode 只在一次性/不可进入时作 muted 后缀；超过 4 个用「还有 N 个子代理」一行。
- 子代理详情：保留主标题行，新增第二行 `← 子代理 <任务名> <状态>`；底栏与主会话同一套「左权限 / 右目录 / 中间瞬态」，左权限槽保留「子代理审批由官方拒绝」事实，不再重复「子代理 · Enter 发送…」。
- 「回到最新」：离开底部时在 transcript 右下显示一行按钮，点击回底；`Ctrl+End` 仍可用。
- 鼠标 hover：第二批实现；若 `MouseEventKind::Moved` 成本过高，可只保留聚焦/选中底色，但需在交付说明中标注。

## 9. 自定细节

- 应用名用 `nano`；设计稿的 `dsh-tui` 视为占位，不追改二进制名。
- 2ch 边距按单元格计，不按浏览器 px；标题/正文/输入/底栏/dock 同步。
- 底栏中段瞬态优先截断；断开/错误等关键状态必须在底栏中段可见，不能只留在 `nano --help` 或会话面板里。
- 上下文合并以「同一轮连续普通注入块」为边界；bash/monitor 保留原标签、不参与合并；工具之间的上下文不合并。
- 工具标签用官方工具名；没有官方名称时用原始工具类别，不发明中文分类。
- 输入区内容 1–8 行、总高 3–10；发送按钮与 Enter 同等有效，Shift+Enter/Ctrl+J 换行沿用现有键位。
- 问卷单选不显示复选框；多选显示 `[x]/[ ]`；焦点指针与选中状态分开；等待文案在活动行。
- `NANO_THEME` 只影响 diff 底色与行内强调，不影响其他 token；默认 `dark`。
- 活动行按 running/等待审批/等待问卷三态；空闲 0 行。
- 子代理详情头保留主标题 + 子代理行；dock 顶边框保留 `N local agents`，行右侧保留活动/时长。
- 审批卡首行白色加粗问句，选项描述下一行 5ch；计划审阅设计稿未展示，沿用 S03 §5。
- 输入区的安全/模式提示（人工命令、附件、队列编辑、子代理 gate）只移位置，不删除。
- 上下文精确值走会话/上下文面板；模型/强度/权限走 `/model` + bare `/permission`；键位说明走 `nano --help` 并补齐缺键。
- hover 是第二批可选项；不做 hover 不影响其余验收，但需在交付说明中标注。
- 新增 Markdown 行内加粗/标题去标记用最小解析，不引入第三方 Markdown 依赖。
- 证据目录 `docs/evidence/2026-10-22-visual/`；不覆盖 0.1.0 已冻结证据。
